# Contributing

Thanks for considering contributing to this project! Here's how you can help.

## Ways to Contribute

- **Report bugs** — Open an issue describing what happened and how to reproduce it
- **Suggest features** — Have an idea? Open an issue with the `enhancement` label
- **Fix bugs** — Fork, fix, and submit a PR
- **Improve docs** — Typos, unclear instructions, missing guides — all welcome
- **Share your build** — Used this template? Open a PR to add your site to the showcase in the README

## Getting Started

1. Fork the repo
2. Clone your fork: `git clone https://github.com/your-username/Web-Portfolio-Template.git`
3. Install dependencies: `npm install`
4. Start dev server: `npm run dev`
5. Make your changes
6. Push and open a PR

## Guidelines

- Keep PRs focused — one feature or fix per PR
- Don't break existing functionality — the template should always build and deploy cleanly
- Follow the existing code style (TypeScript, Tailwind CSS)
- Test on mobile and desktop before submitting

## Code of Conduct

Be respectful. We're all here to build cool stuff.
